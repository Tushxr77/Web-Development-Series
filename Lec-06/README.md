### 1. Search Engine Optimization (SEO)
- Introduction to SEO

### 2. Core Web Vitals
- **CLS (Cumulative Layout Shift):** Measures unexpected movement of page elements.
- **FID (First Input Delay):** Measures the delay before a webpage responds to a user's first interaction. FID has been replaced by INP (Interaction to Next Paint) as a Core Web Vital.
- Understanding webpage user experience and performance.

### 3. Google Lighthouse
- Introduction to Lighthouse
- Inspecting webpages
- Understanding performance and SEO reports
- Identifying areas for improvement
