# Lecture 07 — HTML Forms

## 📚 Overview

In this lecture, I learned about HTML forms and different input elements used to collect information from users.

I created a practice form for a college application to understand how form elements work in HTML.

## 🎯 Topics Learned

- HTML form structure using the `<form>` tag
- Text input using `<input type="text">`
- Password input using `<input type="password">`
- Labels using the `<label>` tag
- Radio buttons for selecting one option
- Checkboxes for optional selections
- Textarea for entering comments
- Dropdown menus using `<select>` and `<option>`
- Form attributes such as `action`, `method`, `name`, `id`, and `value`
- Connecting external CSS using the `<link>` tag
- Basic styling with CSS

## 💻 Practice Project

**Project:** College Application Form

The form includes:

## 🧠 Key Learnings

- The `name` attribute identifies submitted form fields.
- The `id` attribute uniquely identifies an element within a page.
- The `for` attribute connects a label to its input.
- Radio buttons sharing the same `name` allow a single selection.
- Checkboxes allow independent selections.
- The `textarea` tag is useful for longer text.
- The `select` tag creates a dropdown menu.
- The `POST` method sends form data in the request body.
